# prog-for-cybercw1 : security-incident-manager
# BY BIANCA HUGHES - UWS LANARKSHIRE - B01807021

This program will use a dictionary to store information regarding a security incident. This code exists more for the purpose of a concept and requires no user inout. The dictionary will have 3 initialised starting fields for the following: IP Address, Event Type and Risk Level. There will then be code that will do and display the results of the following:
    -Display the username and IP Address of the security incident
    -Add and display a field called status to the dictionary
    -Update and display the risk level of the security incident
    -remove a field from the dictionary
    -Display all remaining keys and values, then the number of all key-value pairs
