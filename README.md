# prog-for-cybercw1 : ip-address-validator
# BY BIANCA HUGHES - UWS LANARKSHIRE - B01807021

This program will ask the user for an IP address, check it amongst a set of formatting rules based on IPv4 using an appropriately named function, then tell the user if the result was valid or not for the formatting of an IPv4 address. For example, the given IP address must contain 3 dots seperating each of the 4 decimal sections of the address, and each decimal section should be between the vales of 0 and 255.
