# prog-for-cybercw1 : security-event-logger
# BY BIANCA HUGHES - UWS LANARKSHIRE - B01807021 

This program will first get to use a temporary username and password. Then, the program will start a loop that asks the user to enter the previously defined username and password, repeating until the result is correct or until the user force-stops the program by entering "Q" as an answer. For each incorrect authentication attempt, an event log will be created and displayed, conveying related information such as; The Event ID, attempted username, IP Address, Event label and the Timestamp which the event occurred.
